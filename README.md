#  Shop App

A complete e-commerce mobile application built using **Flutter**. This project demonstrates modern Flutter development practices, including clean architecture, effective state management using Provider, and seamless UI/UX for a shopping experience.

---

##  Features

-  Product Listing
-  Add to Cart functionality
-  Order Management
-  User Authentication
-  Beautiful UI with Material Design
-  State management with Provider
-  Secure login system
-  Responsive layout for various screen sizes

---

## 🛠️ Tech Stack

- **Flutter** (UI Framework)
- **Dart** (Language)
- **Provider** (State Management)
- **Material Design**
